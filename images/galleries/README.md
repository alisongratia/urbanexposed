# Photo galleries

Each folder here holds the photos for one page/place on the site. Drop your
image files directly into the matching folder using GitHub's web UI
(Add file → Upload files) — no code changes needed to add a photo.

- `home/` — main UrbanExposed page (index.html)
- `odins-underground/` — Odin's Underground page
- `events/` — Events page
- `rentals/` — Rentals page
- `team/` — Team page
- `vendors/` — Vendors page
- `volunteer/` — Volunteer page
- `donate/` — Donate page

Need a gallery for a new place/page? Add a new folder here with the same
naming pattern (lowercase, hyphenated) and let us know so the matching page
can be wired up to display it.
